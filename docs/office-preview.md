# Office 文件预览

在对话里点击文件链接，或从工作区的文件列表打开文档，可以在工作区查看 Office 文件。解析和渲染都在当前浏览器完成，不会把文件上传到第三方文档服务。

| 格式 | 可用操作 |
| --- | --- |
| DOCX | 逐页查看、翻页、缩放，显示文档中的中文文字和内嵌内容 |
| XLSX、XLS | 切换工作表，按 50 行、40 列分组查看，横向滚动 |
| PPTX | 逐张幻灯片查看、翻页和缩放 |
| DOC、PPT | 提供原文件下载；请先用 Office 或 LibreOffice 转换成 DOCX、PPTX |

预览为只读，不会修改原文件。表格显示单元格文字和已保存的公式结果，不计算公式、运行宏或执行单元格中的 HTML。复杂排版、图表、动画和未安装的字体可能与桌面 Office 的显示不同。DOCX 的分页依据文件已有的分节、分页和渲染分页标记，不替代桌面排版引擎。工作表最多预览前 10,000 行；下载原文件可查看完整内容。

预览上限为 8 MiB。文件格式不受支持、内容损坏或解析失败时，界面会说明原因，并保留“重试预览”和“下载原文件”。超过预览上限的文件仍可通过工作区下载。

## 隔离与资源限制

DOCX、XLSX、PPTX 在进入渲染引擎前先检查 ZIP 目录：最多 2,000 项，单项解压后最多 8 MiB，总解压量最多 32 MiB，同时检查压缩比。随后逐项流式解压并检查真实输出大小，避免伪造目录中的大小绕过限制。XML 不接受 DTD 或实体声明，外部文档关系会先移除。

解压和电子表格解析在可终止的 Worker 中运行，单次请求超过 20 秒会终止。离开文件或切换主机会销毁对应的 Worker、预览实例及文档 iframe；再次打开时按当前主机重新读取。

Word 和 PowerPoint 的内容放在独立 iframe 中，禁止脚本、网络连接、表单、对象和子框架。外部图片、字体及媒体不会主动加载，文档链接不执行跳转。表格使用普通文字节点显示，不把单元格内容插入 HTML。

## 依赖与验证

按需加载的窄依赖是 `docx-preview` 0.4.1、`@stackline/xlsx` 1.0.9、`@aiden0z/pptx-renderer` 1.4.0，以及 JSZip 3.10.1。前三者采用 Apache-2.0，JSZip 可按 MIT 许可使用。未引入通用查看器中的 GIS、三维模型或视频处理依赖。

验证覆盖真实结构的中文 DOCX、XLSX、XLS 和 PPTX 文件、翻页及工作表切换、移动端横向滚动、跨主机切换、损坏与旧格式下载回退，以及 ZIP 解压预算、外部关系和 XML 实体拒绝。
