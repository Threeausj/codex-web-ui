# 定时自动化与文件编辑

## 定时任务

侧栏“自动化”管理定时任务和执行记录。新建后选择主机、工作目录、提示、模型、强度、权限与时区；支持每天、每周指定日期和 5 分钟至 7 天的间隔。新任务默认暂停、只读，可以先“立即运行”检查结果，再开启计划。

Web 服务端每 10 秒检查到期任务，关闭网页不影响调度。每次执行创建独立正式会话，执行记录保存会话、轮次、提交 ID、阶段与日志。最多 50 个任务，保留最近 1,000 条记录，面板显示最近 300 条。数据保存到持久 DATA_DIR/automations.json，以 0600 权限原子替换。漏掉的周期合并为一次执行；同任务和同主机不重叠，最多同时启动两台主机，等待队列最多 20 条。暂停计划不停止当前任务，“停止执行”操作用于中断已知轮次。

任务使用所选沙箱和 never 审批策略，主机受管规则仍生效。执行前连接失败可按设置重试 0–3 次。创建会话或提交任务的回执未知时停止自动重试，显示“需要核对结果”；已知会话可打开查看，并只读“核对原生结果”。确认失败或中断后可手动重新执行，操作可能再次修改文件。删除任务取消尚未开始的失败重试，保留执行记录。

Web 服务正常停止或重启后，尚未提交的任务继续排队；已提交任务保留原生 ID 等待核对，不自动重复推理。默认 spawn 模式下，Web 服务关闭会关闭所属 Codex 进程，因此它不保证活动推理跨容器重启继续运行。普通历史、执行记录和定时计划会持久保存。独立 daemon/proxy 的存活范围取决于部署方式。

## 多文件编辑

工作区“文件”最多同时打开 16 个标签。源码编辑器提供行号、按扩展名加载语法高亮、查找、撤销/重做与 Ctrl/Cmd+S 保存。Markdown 可切换排版预览和源码，切换保留草稿；图片直接预览，PDF 在浏览器中分页和缩放，仍可下载原文件。文件查看上限 8 MiB，PDF 与其他二进制不提供文本保存。

JSON、JSONL 和 NDJSON 默认使用只读预览，将字符串中的 Unicode 转义显示为中文或其他可打印字符；保留行号、缩进和大整数的原始数字，不进行 JSON 重新序列化。切换“源码”可查看原始转义并编辑，预览、下载和切换视图不会改写原文件；未保存草稿也可切换预览。字面量反斜杠、控制字符及无效转义保持原样。

CSV、TSV 默认使用分页表格预览。支持逗号、分号、Tab 自动识别，也可手动选择分隔符、是否将首行作为表头；带引号的逗号、双引号和换行保持为同一个单元格。公式与 HTML 仅显示文本，不执行。解析在独立 Worker 中完成，每页 100 行、40 列，最多解析 100,000 行或 1,000,000 个单元格，单个长单元格缩短显示；达到限制时明确提示，源码与原文件下载不变。支持 UTF-8、带 BOM 的 UTF-16LE/BE 和 GB18030；非 UTF-8 文件的源码只读，避免保存时意外转换编码。8 MiB 文件预览限制继续生效。

## 文件复制、移动与上传

文件栏和新建项目的目录选择器共用文件操作：文件行的“…”或右键菜单提供复制、剪切（移动）、重命名、复制路径和删除；目录顶部提供新建文件、新建文件夹、粘贴和上传。聚焦文件行可用 Ctrl/⌘+C、X、V，F2 重命名，Delete 删除；编辑器和搜索框仍保留各自的文本快捷键。

复制或剪切后，进入同一主机的目标目录点击粘贴，确认目标名称。文件夹可递归复制、移动，禁止放入自身或子目录；同名项不会覆盖，可修改目标名称。复制使用磁盘版本，存在未保存草稿时会确认；移动与重命名同步调整打开标签及其草稿。剪切在粘贴成功前不删除源项，跨文件系统的移动会保留源项并提示先复制、核对后再删除。剪贴板限当前登录且绑定主机连接信息，退出登录或主机连接配置变化后清空，不支持跨主机粘贴。复制最多 20,000 个条目、64 层、90 秒，特殊文件和 Windows 链接不会被递归读取；需在目标主机安装 Python 3。

点击上传按钮选取本地文件，或将本地文件拖入文件列表，浮层显示当前目标目录。每批最多 20 个文件、每文件最多 100 MB；暂不支持拖入文件夹。上传固定使用开始时选择的主机和目录，切换会话不会将后续文件写入另一台主机。显示批次进度与逐项失败原因，同名项保留原文件，其他文件继续处理。传输采用登录鉴权与 CSRF 保护的 HTTP 上传，再通过固定 Python 帮助程序和共享 SSH 连接传递二进制数据；完整校验后原子发布，不经过模型或 Base64 WebSocket。中途失败不会发布半个文件，原文件保持不变。

## 文件查看与草稿

点击对话中的文件路径会同时加载所在目录。即使文件超过预览上限，仍会显示并标记对应文件行，可从行末下载按钮保存原文件；已有编辑标签和草稿保留。下载使用经过登录鉴权的 HTTP 流，不经过 Base64 WebSocket 或浏览器内存 Blob，也不受 8 MiB 预览上限限制；本机和 SSH 文件均支持单段 Range 请求。预览先检查文件大小，超限后不会读取整份大文件。SSH 主机需安装 Python 3，并确保非交互 SSH 命令可运行 `python3`，用于安全检查和读取文件；目录浏览仍使用原生 Codex 接口。

源码中选中代码后，可“添加到对话”或“在侧边聊天中提问”，引用携带文件路径与行范围。侧边提问继承当前对话的首次历史锚点并使用独立只读分支；所选代码以引用传入，不修改正在运行的主对话。需先打开一个对话。回复中的 `/path/file:line:column` 链接会打开源码并定位到行。

文件标签和未保存内容按有效登录、主机和项目保存到独立 IndexedDB，保留原始文本与版本以继续检查保存冲突。重连只刷新目录；关闭工作区、换标签、刷新和正常页面回收后可恢复已提交到存储的草稿。明确关闭脏标签需要确认，退出登录会清理私人内容。每次编辑后延迟 180 ms 写入，关闭面板/页面时立即提交写入；突然被系统终止前尚未落盘的最后编辑无法保证恢复。

私人工作存储最多 256 条／64 MiB，也用于未知队列提交和侧边分支保存回执；不静默淘汰未保存工作。浏览器禁用存储或写满时显示警告，内容继续保留在当前页面，未知操作所需的持久回执不能保存时阻止提交。此存储不是加密保险库，同一浏览器用户可访问其网站数据。

保存仍采用原有版本核验，外部修改返回冲突并保留草稿，需手动合并或明确重新载入。下载使用磁盘版本。原生文件 API 没有 CAS，无法消除检查与外部写入之间的所有竞争窗口；详见[可靠性与工作流](reliability-and-workflows.md)。
