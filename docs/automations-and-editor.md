# 定时自动化与文件编辑

## 定时任务

侧栏“自动化”管理定时任务和执行记录。新建后选择主机、工作目录、提示、模型、强度、权限与时区；支持每天、每周指定日期和 5 分钟至 7 天的间隔。新任务默认暂停、只读，可以先“立即运行”检查结果，再开启计划。

Web 服务端每 10 秒检查到期任务，关闭网页不影响调度。每次执行创建独立正式会话，执行记录保存会话、轮次、提交 ID、阶段与日志。最多 50 个任务，保留最近 1,000 条记录，面板显示最近 300 条。数据保存到持久 DATA_DIR/automations.json，以 0600 权限原子替换。漏掉的周期合并为一次执行；同任务和同主机不重叠，最多同时启动两台主机，等待队列最多 20 条。暂停计划不停止当前任务，“停止执行”操作用于中断已知轮次。

任务使用所选沙箱和 never 审批策略，主机受管规则仍生效。执行前连接失败可按设置重试 0–3 次。创建会话或提交任务的回执未知时停止自动重试，显示“需要核对结果”；已知会话可打开查看，并只读“核对原生结果”。确认失败或中断后可手动重新执行，操作可能再次修改文件。删除任务取消尚未开始的失败重试，保留执行记录。

Web 服务正常停止或重启后，尚未提交的任务继续排队；已提交任务保留原生 ID 等待核对，不自动重复推理。默认 spawn 模式下，Web 服务关闭会关闭所属 Codex 进程，因此它不保证活动推理跨容器重启继续运行。普通历史、执行记录和定时计划会持久保存。独立 daemon/proxy 的存活范围取决于部署方式。

## 多文件编辑

工作区“文件”最多同时打开 16 个标签。源码编辑器提供行号、按扩展名加载语法高亮、查找、撤销/重做与 Ctrl/Cmd+S 保存。Markdown 可切换排版预览和源码，切换保留草稿；图片直接预览，PDF 在浏览器中分页和缩放，仍可下载原文件。文件查看上限 8 MiB，PDF 与其他二进制不提供文本保存。

源码中选中代码后，可“添加到对话”或“在侧边聊天中提问”，引用携带文件路径与行范围。侧边提问继承当前对话的首次历史锚点并使用独立只读分支；所选代码以引用传入，不修改正在运行的主对话。需先打开一个对话。回复中的 `/path/file:line:column` 链接会打开源码并定位到行。

文件标签和未保存内容按有效登录、主机和项目保存到独立 IndexedDB，保留原始文本与版本以继续检查保存冲突。重连只刷新目录；关闭工作区、换标签、刷新和正常页面回收后可恢复已提交到存储的草稿。明确关闭脏标签需要确认，退出登录会清理私人内容。每次编辑后延迟 180 ms 写入，关闭面板/页面时立即提交写入；突然被系统终止前尚未落盘的最后编辑无法保证恢复。

私人工作存储最多 256 条／64 MiB，也用于未知队列提交和侧边分支保存回执；不静默淘汰未保存工作。浏览器禁用存储或写满时显示警告，内容继续保留在当前页面，未知操作所需的持久回执不能保存时阻止提交。此存储不是加密保险库，同一浏览器用户可访问其网站数据。

保存仍采用原有版本核验，外部修改返回冲突并保留草稿，需手动合并或明确重新载入。下载使用磁盘版本。原生文件 API 没有 CAS，无法消除检查与外部写入之间的所有竞争窗口；详见[可靠性与工作流](reliability-and-workflows.md)。
