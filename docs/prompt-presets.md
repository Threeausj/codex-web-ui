# 提示词预设

“设置 → 提示词预设”管理 10 个编号槽位；输入 `/presets` 或在命令面板选择“提示词预设”也可直达设置。选择槽位、填写名称与内容后保存；“保存当前草稿”可把输入框的内容带入编辑器。替换、清空和放弃未保存修改均需确认。

- **提示词**：支持多行、Markdown 和公式源文本。输入 `/` 后点击预设，或输入 `/1`～`/10`、预设名称筛选，选择后继续编辑并手动发送；保留原草稿、选中文字和附件，不自动提交。选择时只替换当前 `/` 检索词，前后的正文和附件保留。
- **命令**：保存单行 `/` 命令。目前可执行网页版已有的 `/new`、`/compact`、`/fork`、`/review`、`/terminal`、`/settings`；执行仍遵循原有连接、运行状态和权限限制。其他命令可以保存，但快捷菜单中禁用并提示前往设置修改。命令不会直接交给服务器 shell。
- **跨设备同步**：槽位属于 Web 服务，所有主机共用。保存到私有 `DATA_DIR/prompt-presets.json`，随持久卷备份；重新登录、服务重启及断线重连后恢复。两台设备同时修改同一个槽位会提示冲突，保留本地编辑，需明确重新载入后再修改；不同槽位可分别保存。
- **失败恢复**：读取和保存均有超时；网络错误不会自动重试写入。若提示结果尚未确认，先刷新查看已保存内容，再决定是否重新修改。读取过程中仍可关闭面板，存在未保存编辑或保存请求时暂停 PWA 的自动刷新更新；关闭设置、切换栏目和 Escape 都会检查未保存修改。

此功能参考 [Codex 官方 `/presets` 实现](https://github.com/openai/codex/pull/54380)，提供网页版自己的提示词和命令槽位；不会读写原生 CLI 的 `tui.presets`，也不保存模型或权限配置。单条提示词最多 16,000 个字符，命令最多 2,000 个字符，名称最多 80 个字符。
