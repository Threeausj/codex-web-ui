# 聊天与选文收藏

主聊天右上角或侧栏聊天菜单中的“收藏聊天”保存整个会话，首次可确认收藏名称；再次点击“取消收藏聊天”即可移除。收藏运行中的聊天不会暂停任务，也不会切走正在阅读的会话。

左上角“收藏对话”和项目菜单的同名入口统一展示“聊天”和“选中内容”两种收藏。可以按名称、来源标题和选文内容搜索，重命名收藏或取消收藏；收藏名称不修改原聊天标题。侧栏搜索和命令面板同样支持查找。

点击聊天收藏打开原会话，并沿用会话的阅读位置；点击选文收藏定位、加载并高亮原文。保存了聊天后仍可另外收藏其中的文字，两类记录互不替代。不同主机上的同名或同 ID 会话分别保存；同一主机、同一会话的聊天收藏会去重。

收藏在服务端私有 `bookmarks.json` 中原子保存并持久化，保留项目和主机范围。旧选文收藏继续可读，原消息锚点保持不变。新增的整聊条目使用 `kind: "thread"`，仅保存会话信息；旧镜像不认识此类型，降级前需保留完整备份并迁移新条目，不能直接使用含整聊记录的文件。

新版收藏列表请求通过 `Accept: application/vnd.codex-web.bookmarks.v2+json` 获取两类记录；未升级的旧客户端继续收到原有选文结构，避免仍在线的旧 PWA 解析新类型失败。此协商只影响读取结果，数据仍完整保存在服务端。
