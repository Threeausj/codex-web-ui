# 验证清单

自动检查通过不等于所有桌面功能已验证。特别是实际模型推理、SSH 与同 daemon 桌面实时同步，需要具备相应账户和环境后验证。执行时使用测试工作区，记录 CLI 版本、日期、成功/失败结果。

## 自动检查

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run doctor
npm run doctor:daemon
npm run doctor:preview
```

`tests/protocol.test.ts` 在安装 Codex CLI 后实际启动隔离的 app-server，不使用真实 `CODEX_HOME`，不发 `turn/start`。缺少 CLI 时会跳过，不能将跳过解释为协议验证成功。首次运行 Playwright 前使用 `npx playwright install chromium`；浏览器用例对真实 Vue 页面注入测试专用 HTTP/WebSocket 事件，不发模型请求。

`npm run doctor` 默认只读。`npm run doctor -- --turn` 主动发起一条真实推理并验证第二个 app-server 可以从同数据目录读取会话，结束后归档诊断会话。这项操作使用模型额度，适合部署后主动验证。

## 会话与桌面共享

- 在网页新建测试会话，发送简单消息，检查流式回复与最终完成状态；刷新网页后恢复历史。
- 在同系统账户、同 `CODEX_HOME` 的桌面程序中确认该会话可见，再确认桌面历史能在网页读取。
- 对同 daemon 模式，使用 `codex app-server daemon version` 确认已有服务，设置 `CODEX_CONNECTION_MODE=proxy`；让一个客户端发送消息，另一客户端加入同 thread 并检查事件。默认 socket 不存在时先按实际管理方式配置，不能假设网页自动接上桌面。
- 创建包含多页 turn/item 的测试会话，加载旧历史，检查消息顺序、无重复与分页结束状态。
- Fork 测试对话，确认得到新 id，原会话后续内容互不影响；按 UI 支持范围检查是否能从具体 turn 分支。
- 手动压缩并确认成功事件，恢复后继续发送消息；自动压缩阈值只在支持的模型与有效配置上验证。
- 运行较长 turn 后停止，确认状态为 interrupted，页面可以继续发起新 turn。

## 权限与工具

- 切换只读/工作区写入/完整访问，确认传给 thread/turn 的 sandbox 与 approvalPolicy 实际生效。
- 使用可恢复的测试命令触发审批，分别批准、拒绝，确认 request resolved 后提示消失，拒绝的命令没有执行。
- 若模型发起工具输入或 MCP elicitation，填写回答并确认工作继续；未支持的请求应明确提示。
- 打开终端，检查输出、输入、Ctrl+C、窗口 resize 和退出码；手机断网重连后检查 terminal 状态与连接归属。
- 读取 UTF-8 文件和含 Unicode 文件名的文件，确认上传文件在所选主机可读；图片由模型能识别的输入类型发送。
- 预览 HTML，确认 sandbox 隔离；尝试 `../`、非项目路径与符号链接，确认不会绕过 preview 路径校验。

## 公网入口

- 无登录 Cookie 访问 HTTP API、上传、预览和 WebSocket，确认拒绝。
- 错误 Origin 的 WebSocket、无 CSRF token 的修改请求、错误密码达到频率阈值，确认拒绝。
- HTTPS 登录后确认 Cookie 带 HttpOnly、Secure、SameSite；登出及服务重启后旧 session 不可使用。
- 关闭页面或超过会话有效期后，确认连接不会保留失效的授权。
- 从公网确认只有 HTTPS 入口可达，8787 和原始 Codex transport 没有对外监听。

## SSH 和移动端

- 用运行 Node 的账户预先建立 known_hosts 并验证密钥登录，在目标主机完成 Codex 登录。
- UI 添加 SSH 主机，切换远程绝对目录，读取远程文件、查看远程历史、执行测试终端命令；错误主机密钥应报错。
- 手机在 360px/390px 视口下检查登录、会话抽屉、审批、附件、终端和预览，确认按钮可点击、无横向溢出。
- 软键盘打开时检查输入框可见，发送按钮仍可操作；桌面检查 Cmd/Ctrl+K 唤醒页面内命令面板。
- 断网重连后确认 pending approvals 可恢复，失败的发送不会被自动重复执行。
