# 聊天标签页

顶部左侧以标签页显示已经打开的聊天。点击标签可切换聊天，`＋` 打开当前主机／项目的新对话。右侧保留侧边聊天与工作区入口；所属主机在侧栏与设置中查看，顶部不再重复显示设备徽标。

当前标签中的 `…` 提供聊天操作和“固定标签页”。固定的标签排在前面，在同一浏览器重新打开页面后保留；它独立于侧栏置顶和收藏聊天。取消固定恢复普通标签，固定标签也可从菜单中明确关闭。

关闭标签只移除打开入口，不归档、删除或停止聊天。关闭当前标签会切换到邻近标签；最后一个关闭后显示新对话。切换沿用现有连接、每个聊天的草稿与阅读位置，底部跟随状态也分别保留。原生归档、删除及移除主机会清理对应标签，同一原生 ID 在不同主机之间独立。

草稿同时保存文字、图片和文件附件，按主机与聊天隔离；切换标签不会清除上传完成的附件，上传中切换也只将结果留在原聊天。图片预览与原始文件保存在当前浏览器的私人存储，刷新后可恢复，不通过聊天标签同步到其他设备。网站存储不可用或超过私人存储预算时，会明确提示只能在当前页面保留，避免静默丢失附件。发送成功或手动移除附件后清除对应草稿。

跨主机切换会复用已访问主机的健康连接；首次连接或真实断线仍需等待。附件保留原主机归属，进入另一台主机的聊天不会带入旧主机路径。新对话主动改变目标主机时，仍将原始文件重新上传至目标主机。

标签栏可横向滚动，活动标签自动进入可见区域，不滚动聊天正文。键盘左右方向键、Home、End 移动标签焦点，Enter 切换，Delete 关闭普通标签。菜单支持方向键与 Escape，关闭后将焦点还给入口。手机保留新建、侧边聊天和工作区按钮。

标签只记录主机 ID、聊天 ID、标题、固定状态和最近打开时间，使用当前登录的私人浏览器存储，不额外缓存聊天正文。最多保留 24 个标签，其中最多固定 23 个，为新聊天预留一个位置；超过上限时释放最久未打开的普通标签，任务与草稿不受影响。网站存储不可用时，标签仍可在当前页面使用；标签不跨设备同步。
