# 主机设置与终端

设置顶部的“设置主机”控制 Codex、性能、配置和技能/集成页面的目标；它不会切换当前聊天或清除草稿。外观、网页密码、应用通知和 Web 导航偏好适用于整个应用。

## 停用本机 Codex

部署服务器不必同时作为 Codex 执行主机。在 **设置 → 连接 → 本地主机** 点击“停用”，可移出本机执行节点，Web 服务、网页登录和远程 SSH 主机继续工作。停用后不会再自动启动本机 Codex。

本机项目、会话历史、配置及收藏保留在原位置。在同处点击“启用”即可恢复本机入口。停用状态在 Web 服务重启后保留；没有其他执行主机时，页面提供添加 SSH 连接或重新启用本机的入口。

本机仍有活动对话、审批、终端或自动化执行时，服务端拒绝停用并提示先结束这些工作，以免中断任务。

## 紧凑布局

支持服务层级的模型会在输入框中直接显示当前主机返回的 Fast 或原生默认，无需先点击选择器。另一设备修改当前对话的速度后，已连接页面同步更新；原生返回但模型目录未列出的层级保留真实名称，不显示空白。支持切换的层级仍以原生目录和接口能力为准。

主会话、侧栏和工作区使用对齐的紧凑顶栏。工作区视图导航与关闭按钮合为一行；窄面板中保留当前视图名称，其他视图显示带提示的图标，所有按钮保留可访问名称。手机继续保留触控操作空间。

工作区宽度不超过 350 px 时，全部视图使用图标，保留选中标记、名称提示和关闭按钮。

## 已归档的聊天

在设置选择主机后，打开“已归档的聊天”管理该主机的归档，无需切换当前聊天。可搜索标题、按项目筛选并加载更多；项目分组及数量以已加载的列表为准。点击聊天标题取消归档，聊天菜单支持永久删除，删除前需再次确认。

切换设置主机或搜索时会作废旧请求；不会将上一台主机的归档混入当前列表。

## 更新 Codex 信息

在目标主机更新 Codex 后，打开 **设置 → 性能 → 重新连接 Codex**。Web 会重新初始化连接并读取版本、全部模型分页、配置与技能。模型和上下文容量来自原生接口，不根据模型名称猜测容量。

“刷新信息”只读取现有连接。重新连接会重启 Web 自己管理的 Codex 子进程；代理模式只重建本客户端连接，共享 daemon 的升级需要先在宿主机完成。已释放的主机在资源管理中恢复。对话、子智能体、审批、终端、后台命令或自动化尚未完成时，服务端拒绝重启；关闭终端或等待任务完成后重试。

配置报告的 `model_context_window` 与当前对话已使用的窗口分别显示。旧会话可能保留原生运行时的容量，更新后的配置是否应用以之后的原生 token 使用事件为准。

## 更新并重启 Codex

在 **设置 → 连接** 点击目标主机的下载按钮，或在 **设置 → 性能 / Codex** 找到“更新并重启 Codex”。它在所选主机执行原生 `codex update`，读取安装版本，再重启 Web 管理的 App Server，核对实际运行版本并刷新模型、配置等信息。命令更新到 CLI 自身提供的最新版本，不固定为 0.165.0。

服务端先检查运行中的对话、审批、终端、待执行消息和自动化，并在整个操作期间保留维护锁。忙碌时拒绝更新；不强制停止任务。共享代理由外部管理，不能用此按钮升级或重启。更新使用原有执行账户、CLI 路径和 Codex 数据目录，保留配置与认证，不自动提升权限。

更新在服务器后台继续，关闭设置不会取消；重新打开可查看进度。请求超时会先查询操作记录，无法确认时只允许用户重新提交同一请求编号，避免重复执行。安装命令失败时保留原连接；安装成功但重启或版本核对失败时显示具体状态，处理后可重新连接。更新程序需要目标安装目录的写权限；只读容器安装应通过镜像部署更新。

## 中转站和官方账号

**设置 → Codex → 中转站** 输入兼容 Responses API 的 API 根地址（例如 `https://api.example.com/v1`）、API Key 和可选默认模型，再保存。第一次配置或更换地址时需要 Key；同地址留空保留已保存的 Key。切换提供方不自动升级主机的 Codex。

使用官方的[命令式认证配置](https://learn.chatgpt.com/docs/config-file/config-reference)把 Key 保存在目标主机 Codex 数据目录下的独立 `0600` 文件，不通过读取设置回传 Key，也不替换官方 `auth.json`。此功能要求主机 Python 3 和支持 `model_providers.<id>.auth` 的 Codex。切换提供方会影响该用户的 Codex 配置；共享代理模式须在服务端修改。

保存后读取实际生效的提供方。若项目配置、配置档或启动参数覆盖了用户配置，页面显示覆盖提醒和真实结果。

选择 **官方账户 → 保存提供方 → 登录 ChatGPT** 后，打开显示的授权页面并输入设备码。Web 自动检查登录状态，也提供手动检查、复制验证码和取消登录。设备码流程使用[官方 App Server 登录接口](https://learn.chatgpt.com/docs/app-server)，无需把 NAS 的 localhost 回调端口暴露给手机。网页登录密码与模型账户独立管理。

## Vertex AI 与记忆

Codex 0.165.0 起可在 **设置 → Codex → Vertex AI** 选择原生 `gcp` 提供方。先在目标主机配置 `GOOGLE_CLOUD_PROJECT` 与 gcloud Application Default Credentials；`GOOGLE_CLOUD_LOCATION` 可选，省略时使用原生默认区域。网页沿用主机认证，不收集 Google 凭据，不修改主机环境变量。提供方可选填默认模型；旧版主机显示升级提示。

同页的“记忆”提供手动读取主机记忆状态、当前已打开会话的记忆摘要。它按接口能力检测，不自动开启记忆、不迁移旧资料，也不导入外部记忆；没有摘要时明确显示空状态。切换主机、会话或登录身份后丢弃旧结果。

## 多终端

工作区终端支持标签、新建、切换与单独关闭，后台标签继续缓存输出。关闭工作区或切换到文件页面不会关闭 Shell；点击终端标签的关闭按钮才会终止对应连接。Tmux 标签关闭只分离客户端。

默认优先使用用户配置的交互 Shell（Bash、Zsh、Fish、Ksh），否则回退 Bash，最后使用 `sh`。Tab 和命令历史由 Shell 提供；只有 `sh` 的主机可能没有补全。手机提供 Tab、方向键、Esc、Ctrl+C 等控制键，以及复制选中、粘贴和回到最新输出。

保留现有 [xterm.js](https://xtermjs.org/) 与原生 PTY，参考 [ttyd](https://github.com/tsl0922/ttyd) 和 [WeTTY](https://github.com/butlerx/wetty) 的终端交互；没有新增独立终端服务。

## 发送与压缩

输入框只显示一个操作按钮：有文字、引用、文件或技能时发送；空白且任务运行时停止。压缩上下文期间仍可提交，按钮显示“压缩结束后发送”，压缩结束后按选定的发送方式投递一次。断连、切换会话或压缩失败会取消等待并保留草稿。
