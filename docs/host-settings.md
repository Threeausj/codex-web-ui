# 主机设置与终端

设置顶部的“设置主机”控制 Codex、性能、配置和技能/集成页面的目标；它不会切换当前聊天或清除草稿。外观、网页密码、应用通知和 Web 导航偏好适用于整个应用。

## 更新 Codex 信息

在目标主机更新 Codex 后，打开 **设置 → 性能 → 重新连接 Codex**。Web 会重新初始化连接并读取版本、全部模型分页、配置与技能。模型和上下文容量来自原生接口，不根据模型名称猜测容量。

“刷新信息”只读取现有连接。重新连接会重启 Web 自己管理的 Codex 子进程；代理模式只重建本客户端连接，共享 daemon 的升级需要先在宿主机完成。已释放的主机在资源管理中恢复。对话、子智能体、审批、终端、后台命令或自动化尚未完成时，服务端拒绝重启；关闭终端或等待任务完成后重试。

配置报告的 `model_context_window` 与当前对话已使用的窗口分别显示。旧会话可能保留原生运行时的容量，更新后的配置是否应用以之后的原生 token 使用事件为准。

## 中转站和官方账号

**设置 → Codex → 中转站** 输入兼容 Responses API 的 API 根地址（例如 `https://api.example.com/v1`）、API Key 和可选默认模型，再保存。第一次配置或更换地址时需要 Key；同地址留空保留已保存的 Key。网页不会自动下载或升级主机的 Codex。

使用官方的[命令式认证配置](https://learn.chatgpt.com/docs/config-file/config-reference)把 Key 保存在目标主机 Codex 数据目录下的独立 `0600` 文件，不通过读取设置回传 Key，也不替换官方 `auth.json`。此功能要求主机 Python 3 和支持 `model_providers.<id>.auth` 的 Codex。切换提供方会影响该用户的 Codex 配置；共享代理模式须在服务端修改。

保存后读取实际生效的提供方。若项目配置、配置档或启动参数覆盖了用户配置，页面显示覆盖提醒和真实结果。

选择 **官方账户 → 保存提供方 → 登录 ChatGPT** 后，打开显示的授权页面并输入设备码。Web 自动检查登录状态，也提供手动检查、复制验证码和取消登录。设备码流程使用[官方 App Server 登录接口](https://learn.chatgpt.com/docs/app-server)，无需把 NAS 的 localhost 回调端口暴露给手机。网页登录密码与模型账户独立管理。

## 多终端

工作区终端支持标签、新建、切换与单独关闭，后台标签继续缓存输出。关闭工作区或切换到文件页面不会关闭 Shell；点击终端标签的关闭按钮才会终止对应连接。Tmux 标签关闭只分离客户端。

默认优先使用用户配置的交互 Shell（Bash、Zsh、Fish、Ksh），否则回退 Bash，最后使用 `sh`。Tab 和命令历史由 Shell 提供；只有 `sh` 的主机可能没有补全。手机提供 Tab、方向键、Esc、Ctrl+C 等控制键，以及复制选中、粘贴和回到最新输出。

保留现有 [xterm.js](https://xtermjs.org/) 与原生 PTY，参考 [ttyd](https://github.com/tsl0922/ttyd) 和 [WeTTY](https://github.com/butlerx/wetty) 的终端交互；没有新增独立终端服务。

## 发送与压缩

输入框只显示一个操作按钮：有文字、引用、文件或技能时发送；空白且任务运行时停止。压缩上下文期间仍可提交，按钮显示“压缩结束后发送”，压缩结束后按选定的发送方式投递一次。断连、切换会话或压缩失败会取消等待并保留草稿。
