# 实时 Markdown 输入

聊天输入框默认边输入边显示标题、粗斜体、删除线、行内／围栏代码、列表和引用。光标进入某段格式时显示其 Markdown 标记，便于继续编辑；原文始终按 Markdown 保存和发送。草稿中的链接和图片只作编辑提示，不会在输入时打开网页或加载远程图片。

| 操作 | 快捷键或行为 |
| --- | --- |
| 粗体／取消粗体 | Ctrl／⌘ + B |
| 斜体／取消斜体 | Ctrl／⌘ + I |
| 行内代码／取消代码 | Ctrl／⌘ + E |
| 插入／取消链接 | Ctrl／⌘ + Shift + K，仅输入框内；Ctrl／⌘ + K 仍为命令面板 |
| 续写列表、任务列表或引用 | 在已有内容的条目中按 Enter；有序列表自动递增 |
| 退出列表或引用 | 在空条目中按 Enter；嵌套条目逐层退出 |
| 普通换行 | Shift + Enter；围栏代码中也可直接 Enter |
| 发送 | 普通文字中 Enter，或任意位置 Ctrl／⌘ + Enter；也可点击发送按钮 |
| 撤销／重做 | Ctrl／⌘ + Z、Ctrl／⌘ + Shift + Z |

中文输入法确认候选词时不会发送。附件粘贴、`/` 指令与预设、`@` 模式／文件选择继续使用原来的入口。不同主机和会话的草稿及撤销记录分别隔离，切换后撤销不会恢复另一会话的文字。

工具栏的眼睛按钮仍可打开完整预览，以查看表格、公式等排版；Esc 或“编辑 Markdown”返回实时编辑器。完整预览最多解析前 100,000 字符，发送原文不因此截断。
