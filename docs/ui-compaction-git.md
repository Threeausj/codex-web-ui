# 自动化布局、压缩记录与 Git 目录

自动化窗口使用统一的标题、任务列表、状态标签和执行记录样式。无任务时缩小窗口；桌面表单两列对齐，手机改为单列并隐藏编辑时的任务列表，给表单留出空间。窄屏可滚动表单，底部保留取消与保存按钮。

压缩记录不是固定的对话页脚。展开工作过程时，按原始操作顺序显示压缩前的记录、压缩标记及之后的进展和回复；收起时只保留可见回复与压缩标记，避免重复。完成、重连以及按需加载后仍保留原来的先后顺序。

Git 面板显示并允许选择独立的仓库目录。当会话在 `/` 等非仓库目录启动时，优先从最近的操作目录和当前主机的项目中查找。摘要历史没有操作元数据时，只读取最多 40 条最近原生条目，再验证最多 8 个候选目录；不会扫描整个主机，也不会初始化仓库或改变会话的工作目录。读取失败显示明确的目录提示，成功恢复后不留下全局报错。

当前 NAS 会话在 `/` 启动，项目源码迁移后位于 `/volume2/docker/codex-web-ui`，因此直接在会话目录执行 Git 会报 `not a git repository`。仓库识别后的状态、差异和工作树操作使用已显示的实际仓库路径。所有权限档位的固定 Git 查询使用后台只读接口；写入仍由 Codex 执行，并使用所选权限。
