# SSH 连接复用与采集调度

Codex RPC、交互终端、文件读取／下载、Python 读取助手和开发服务转发使用应用私有的 OpenSSH ControlMaster 连接池。相同主机身份下的功能通道复用 SSH 认证和 TCP 连接；关闭单个功能只释放该通道，其他工作继续。保持系统 OpenSSH 的 SSH config、agent、私钥与严格主机指纹行为，不要求安装另一套远端服务。

连接身份包含解析后的 SSH 配置、私钥身份、已确认的主机指纹等。配置或信任变化创建新连接；删除或明确重置主机时关闭其连接。控制 socket 位于随机的私有 0700 目录，不复用用户已有的外部控制 socket。服务关闭会清理自己的主连接和临时目录。

后台资源与 tmux 采集按主机串行、限制排队并对失败退避，交互操作直接执行，避免后台采集占满请求队列。连接空闲后回收；需要时重新认证。它减少反复握手成本，不保证慢网络和远端系统本身不会超时。

隔离真实 sshd 验证覆盖多个并行通道、Python 文件读取与采集、SFTP 传输复用一次公钥认证，以及错误指纹拒绝；没有通过放宽主机校验实现复用。
