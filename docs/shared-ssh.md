# SSH 连接复用与采集调度

Codex RPC、交互终端、文件读取／下载、Python 读取助手和开发服务转发使用应用私有的 OpenSSH ControlMaster 连接池。相同主机身份下的功能通道复用 SSH 认证和 TCP 连接；关闭单个功能只释放该通道，其他工作继续。支持系统 OpenSSH 的 SSH config、agent、私钥、密码登录与严格主机指纹校验，不要求安装另一套远端服务。

连接身份包含解析后的 SSH 配置、私钥身份、已确认的主机指纹等。配置或信任变化创建新连接；删除或明确重置主机时关闭其连接。控制 socket 位于随机的私有 0700 目录，不复用用户已有的外部控制 socket。服务关闭会清理自己的主连接和临时目录。

后台资源与 tmux 采集按主机串行、限制排队并对失败退避，交互操作直接执行，避免后台采集占满请求队列。连接空闲后回收；需要时重新认证。它减少反复握手成本，不保证慢网络和远端系统本身不会超时。

隔离真实 sshd 验证覆盖多个并行通道、Python 文件读取与采集、SFTP 传输复用一次公钥认证，以及错误指纹拒绝；没有通过放宽主机校验实现复用。

在“设置 → 连接”添加或编辑主机，选择“密码登录”，输入 SSH 账户密码后测试或保存。密码与私钥使用同一个连接池，Codex、文件、终端及端口转发会复用已认证的连接。测试未保存的配置会创建独立临时连接，结束时释放。编辑同一账户时密码留空会保留原值；修改账户、地址或端口须重新输入，切换到 SSH 配置／身份文件会移除已保存密码。

密码使用 AES-GCM 加密保存在 `DATA_DIR/hosts.json` 中，密钥为同目录的 `ssh-password.key`；两者均仅服务端用户可读。备份或迁移时须同时保留这两个文件。网页只收到“已保存密码”状态；连接时通过私有临时 socket 提供密码，命令参数、环境变量与临时脚本中均不包含密码。主机指纹仍需先确认，错误密码不会回退复用旧凭据连接。
