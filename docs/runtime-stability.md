# 会话上下文与连接恢复

输入框中的上下文用量来自当前会话的 `thread/tokenUsage/updated`。首次打开或浏览器缓存被系统清理后，服务端会以只读方式补读对应 Codex 会话记录中的最新 token 统计。只返回计数，不返回记录内容；读取不恢复会话写入者，也不启动模型请求。暂时缺失的窗口大小会保留上次有效值，真实未知的用量仍显示 `—`。

手机和桌面点击上下文指示器，均先在浮层中查看已用／总窗口 token 数、比例及“立即压缩”；只有点击“立即压缩”才发送压缩请求。浮层不改变消息区或输入框高度；任务运行中仍可查看用量，压缩按钮会说明暂不可用的原因。可点击关闭按钮、指示器或浮层外部收起；手机返回先关闭浮层。手机软键盘改变可见区域时，浮层会重新定位并限制高度。

`thread/compact/start` 的 `{}` 响应只表示请求已接收。压缩提醒持续到实际完成；完成事件遗漏时，通过权威空闲状态、已完成的历史记录或同回合后续的新回复校正。压缩期间每两秒只读核对上下文与轻量运行状态，结束后停止；不重新加载大对话、获取写入锁或重发请求。自动压缩结束后，整轮任务仍运行也可恢复追加指令。失败、取消与断线保留待发送草稿；旧检查结果和迟到的旧完成事件不能解除较新的压缩。已完成的压缩分隔线留在原来的回合位置，后续消息出现在其下方。多个页面同时压缩时，一个被拒绝的请求不会清除已经运行的压缩提示。

每台主机继续复用一条原生 app-server 连接。服务端通过 `engineId` 和事件序号标记连接连续性，网页恢复到前台时使用 `bridge/ping` 检查；连续的连接不会重新加载历史、配置或争夺写入者。丢失事件时只读补齐历史，原生进程变化时重新确认写入资格。旧服务器继续使用兼容的保守恢复流程。SSH 使用应用层保活，网页 WebSocket 容许短暂后台暂停；真正失效的连接仍会超时重连。

同一主机内切换对话复用网页 WebSocket；目标主机还在连接或读取配置时，继续选择该主机的其他对话也复用正在进行的连接，最后一次选择生效。跨主机切换时，网页需要改连绑定新主机的 WebSocket，界面显示“正在连接目标主机”，不会把主动切换误报为断线。服务端原有 Bridge、SSH 和 Codex 进程继续保留，浏览器离开不会终止其任务；显式释放连接、修改主机配置或重启服务仍可能重新建立原生连接。

进入或切回正在运行的对话时，工作过程和操作批次自动展开，历史摘要中的过程记录按需补读；单条命令输出及文件差异仍可单独展开。运行期间手动收起不会被后续增量打断，实际完成、失败或停止后自动折叠，最终答复保留在外面。

离开会话时单独保存是否跟随最新消息。在底部离开，返回后会滚动到当前最新内容，并继续跟随增量输出、图片与过程记录的延迟布局；向上阅读后离开，返回时按历史区块与相对偏移恢复阅读位置，运行中的新输出不会拉走视图。点击向下箭头或主动滚到底部可恢复跟随。位置按登录、主机和会话隔离，兼容先前保存的绝对滚动位置。

运行诊断中的 `lastDisconnect` 在重连成功后保留最近一次原生连接断开的时间、固定原因分类及当时活跃对话数，方便区别传输关闭、写入失败、无效协议帧、初始化失败与显式释放。它仅保存在当前服务进程内存中，不保存原始错误、命令、消息或 SSH 输出；服务重启后清空。重连后 `lastError` 清除不再导致这条诊断消失。

停止按钮使用当前运行轮次的 ID。历史恢复取最新的 `inProgress` 轮次，避免旧轮次标记覆盖当前任务；遇到明确的 `expected active turn id … but found …` 冲突时，只读核对最近一轮摘要，确认同一会话的运行轮次后最多重试一次。切换会话、登录身份变化、重连、轮次已完成或不确定的网络失败都会阻止重放。重复点击共用正在提交的停止请求；Goal 暂停仍与停止请求并行，暂停失败会提示状态需确认。侧边聊天使用同样的冲突核对，并限定为独立分支，不会停止主对话。

发送按钮在发送后继续占据原位置，草稿为空时禁用；停止按钮使用独立位置，因此快速连点发送或追加指令不会意外触发停止。客户端和服务端都拒绝直接归档仍在运行的会话，需先显式停止或等待完成。

工作区的 Git 查询使用固定的只读命令集合，禁用 hooks、fsmonitor、外部 diff、textconv、clean/process 过滤器及可选索引写入，因此不依赖 Linux 用户命名空间。默认权限的 Git 写入仍使用 Codex 沙箱；NAS 不支持沙箱时显示明确原因。用户选择完全访问后，Git 读取和写入都使用该权限。

普通“完全访问”始终对应 `dangerFullAccess` 与 `approvalPolicy: never`；命名预设保留用户指定的审批规则，主机管理策略继续有效。已在运行的回合保留启动时的权限，因为 `turn/steer` 不接受权限覆盖；运行中改变全局权限时会提示下一轮生效。

子智能体的最新对话在主对话打开后自动预读，最多同时读取三个，点击详情直接使用内存缓存。实时事件更新未选中子智能体的内容；切换主机、主对话或退出登录会清理缓存。预读只使用 `thread/read` 与历史分页，不会获取子智能体写入锁。
